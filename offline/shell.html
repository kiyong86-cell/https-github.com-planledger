한글(HWPX) 변환기

워드(.docx) 문서를 한글 문서로 바꿉니다. 표·병합·색상·정렬을 유지합니다.

🔒 인터넷 연결 없이 이 컴퓨터 안에서만 처리됩니다
📄 워드 파일(.docx)을 끌어다 놓거나 눌러서 선택하세요 · 여러 개 가능
체험판입니다
변환 횟수 제한은 없습니다. 서식 변환 품질도 정식판과 완전히 같습니다.
다만 변환된 문서 맨 앞에 체험판 표시 한 줄이 들어갑니다. 그대로 제출·보고에 쓰기 어려우니, 실제 업무에 쓰실 때는 아래로 문의해 주세요.
사용 방법
이 파일을 더블클릭하면 바로 열립니다. 설치·회원가입·인터넷 연결이 필요 없습니다.

저장 위치
변환된 파일은 브라우저의 «다운로드» 폴더에 저장됩니다. 파일이 1개면 .hwpx 로, 2개 이상이면 .zip 하나로 묶여 저장됩니다.

보안
문서가 외부로 전송되지 않습니다. 네트워크가 차단된 환경에서도 동일하게 동작합니다.
