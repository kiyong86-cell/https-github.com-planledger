# 사업계획서 & 영수증 관리 사이트

사업계획서를 템플릿에 맞춰 작성하고(Word 내보내기 가능), 영수증 사진을 첨부해 정리하는 개인용 웹앱입니다.

**가입도, 로그인도, 인터넷 서비스 연결도 필요 없습니다.** 모든 데이터는 이 폴더 안 `data/` 에 저장됩니다.
(Supabase를 연결해 클라우드 모드로 웹에 공개하는 방법은 [웹배포_가이드.md](웹배포_가이드.md) 참고 — 이 경우 이메일 회원가입 로그인이 추가됩니다.)

## 실행 방법

이 폴더의 **`시작하기.bat`** 파일을 더블클릭하세요. 잠시 후 브라우저가 자동으로 열립니다.

- 주소가 자동으로 안 열리면 브라우저에서 직접 http://localhost:3000 으로 접속하세요.
- 검은 명령창을 닫으면 사이트가 종료됩니다. 사용하는 동안은 켜두세요.
- 데이터는 사이트를 껐다 켜도 그대로 유지됩니다.

## 기능

- **기획안**: 내부/외부 기획안 선택, 주제(섹션) 자유 추가·수정·순서변경, 일정표(셀 병합 가능), 예산안(산출 내역 포함), 사진 첨부.
  **Word(.docx)**와 **한글(.hwpx)** 두 형식으로 내보내기, 브라우저 인쇄로 PDF 저장 가능. 지원사업 정산 보고서 등 .hwp 제출이 필요한 경우 한글 내보내기를 사용하세요.
- **영수증 관리**: 날짜·상호·금액·카테고리·메모 입력 + 사진(또는 PDF) 첨부.
  **사진을 올리면 무료 OCR이 날짜·금액·상호를 자동으로 읽어 입력칸에 채워줍니다** (확인 후 저장).
  처음 한 번은 인식 데이터를 인터넷에서 내려받으므로 인터넷 연결이 필요하고, 이후엔 캐시되어 빨라집니다.
  월별/카테고리 필터, 합계 자동 계산, CSV 내보내기(엑셀에서 바로 열림).

## 데이터 백업

`data/` 폴더만 복사해두면 전체 백업이 됩니다. (사업계획서, 영수증 목록, 첨부 사진 전부 포함)

## 나중에 확장하고 싶다면

- **여러 기기에서 사용 / 계정 로그인**: Supabase 같은 클라우드 DB를 붙이면 됩니다 (무료 요금제 있음, 가입 필요).
- **AI 초안 작성 / 영수증 자동 인식(OCR)**: Claude API 키를 발급받으면 붙일 수 있습니다 (사용량만큼 과금).

두 가지 모두 지금 구조에서 코드를 추가하는 방식으로 확장 가능합니다.
